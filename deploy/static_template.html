AI Data Analyst

Ask a business question in plain English, or upload a CSV. A LangGraph agent writes SQL with a fine-tuned 3B text-to-SQL model, waits for your approval, runs it read-only through MCP tools, corrects its own failed queries, then charts and summarizes the result.

Evaluation

52 questions with hand-written reference SQL on the demo shop (34 with a single correct answer, plus ambiguous, unanswerable and adversarial ones) and 11 on a CSV none of the models had seen. Both 3B models get the identical prompt, so only the weights differ.

At 3B neither model is clearly better: the fine-tune wins on the unseen CSV and loses on the shop, mostly by answering in benchmark shape (only the asked-for value, no measure to chart). Sending only question-relevant hints lifted the fine-tune from 35% to 62% on the shop questions. Full scorecards are in the repository.

How it works

A LangGraph state machine. Every step that touches data goes through an MCP server.

Load schema

MCP describe_schema: tables, sample rows and dataset notes.

Write SQL

SQLForge-3B in its training format, with only the hints this question needs.

Human approval

LangGraph interrupt(): approve, edit or reject.

Run read-only

SQL guard plus a read-only connection. Errors go back to the model to self-correct.

Chart

Chart type chosen by a small model; long-format results split into series.

Summarize

Facts computed in code; a summary with any untraceable number is replaced.

Run it yourself

The live app (both tabs, your own CSVs) runs on any machine with about 4 GB of free RAM. The models download on first start.

git clone __REPO_URL__ && cd agent_analyst
pip install -r requirements.txt -r requirements-app.txt
ANALYST_SQL_MODEL=hf://ay2r/sqlforge-3b/gguf/sqlforge-3b-Q4_K_M.gguf python app.py   # http://127.0.0.1:7860

Or with Docker: docker build -t analyst . && docker run -p 7860:7860 analyst. Sample file used on this page: sample_coffee_sales.csv.

Built with LangGraph, MCP, llama.cpp and matplotlib. Model: SQLForge-3B. Every answer on this page was produced by the agent and checked against reference SQL.
